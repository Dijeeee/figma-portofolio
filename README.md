# 📖 Tentang Project

**Jaya Store** merupakan desain UI/UX aplikasi marketplace yang dibuat khusus untuk mempermudah transaksi jual beli item game **Roblox Blox Fruits**.

Project ini dibuat sebagai bagian dari portfolio UI/UX Design dengan fokus pada pengalaman pengguna (User Experience) dan tampilan antarmuka (User Interface) yang modern, sederhana, dan mudah dipahami.

---

# 🎯 Tujuan Project

- Mendesain aplikasi marketplace game.
- Memberikan pengalaman pengguna yang sederhana.
- Mempermudah proses transaksi item game.
- Membuat desain yang modern dan responsif.
- Mengimplementasikan Design System yang konsisten.

# 💡 Studi Kasus

## Permasalahan

Proses transaksi item game Roblox masih banyak dilakukan melalui media sosial atau aplikasi pesan sehingga kurang praktis, kurang aman, dan tidak memiliki alur transaksi yang jelas.

## Solusi

Jaya Store hadir sebagai konsep aplikasi marketplace yang menyediakan proses pencarian produk, pembelian, pembayaran, hingga komunikasi dengan penjual dalam satu aplikasi.
